# Pythagoras Mobile

The production Student client for Pythagoras Platform, built with Expo SDK 57,
React Native, TypeScript, and Expo Router.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app on the local network

   ```bash
   npx expo start --lan
   ```

Scan the terminal QR code with an SDK 57-compatible Expo Go build. Routes live
in `app/`; reusable code belongs outside that directory as it is introduced.

### Other setup steps

- Run `npm run lint` to lint the mobile routes.
- If you'd like to set up unit testing, follow our guide on ["Unit Testing with Jest"](https://docs.expo.dev/develop/unit-testing/)
- Learn more about the TypeScript setup in this template in our guide on ["Using TypeScript"](https://docs.expo.dev/guides/typescript/)
