# Pythagoras

واجهة محلية لمنصة فيثاغورس: تطبيق الطالب ولوحة الإدارة.

## التشغيل على Windows

المتطلبات: Node.js 20.9 أو أحدث وnpm.

```powershell
npm install
npm run dev
```

افتح `http://localhost:3000` لتطبيق الطالب، أو `http://localhost:3000/admin` للإدارة.

التحقق:

```powershell
npm run typecheck
npm run lint
npm run build
```
